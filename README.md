# SimpleSpellChecker

**SimpleSpellChecker** is a lightweight World of Warcraft addon that tracks and displays missing Level 60 trainer spells and AQ20 class books for your current character.

## Features
* Quickly check which endgame spells your character is still missing.
* Tracks Level 60 trainer-taught spells.
* Tracks Ahn'Qiraj 20 (AQ20) class book spells.

## Slash Commands
Use the following command in-game to open the interface or options:
* `/ssc` or `/simplespellchecker`

## Minimap-Button
Use the Minimap Button to Open the Window

## Installation
1. Download the addon.
2. Extract the folder into your World of Warcraft directory: `World of Warcraft\Interface\AddOns\`
